# Green Basket Demo School

A clean, realistic marketing demo for **Green Basket Global's private-school management system**.

## Demo workflow

Dashboard → Students → Classes → Attendance → Fees & Payments → Results → Reports

## Demo roles

- Owner / Admin
- Accountant / Cashier
- Teacher
- Parent
- Student

## Goal

This repository is intentionally small and polished. It demonstrates the core school workflow with realistic Nigerian private-school data and responsive screens, without pretending to be the full production application.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Source of truth

Production application: `greenbasket-labs/school-management-system`
