# Green Basket Demo School

Marketing demo for Green Basket Global's private-school management system.

This repo is intentionally built as a clean, simple, realistic school demo using the production application as its source of truth.

## Demo goal

A visitor should be able to enter a real sample school and use the core workflow:

Dashboard → Students → Attendance → Fees & Payments → Results → Reports

Representative demo roles:

- Owner / Admin
- Accountant / Cashier
- Teacher
- Parent
- Student

## Build rule

Keep the demo simple, polished, responsive, and functional. No fake dashboard numbers, no dead navigation, and no unnecessary enterprise features.

## Source of truth

Production repository:
`greenbasket-labs/school-management-system`

## Status

Fresh demo repository created. Production source will be copied first, then demo-specific branding/data will be layered on top and verified with a clean install, Prisma generation, build, seed, and runtime checks.
